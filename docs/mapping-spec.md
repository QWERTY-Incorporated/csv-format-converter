# 変換定義（mapping JSON）仕様

変換定義は「入力 CSV のどの列を、どう加工して、出力テンプレートのどの列に入れるか」を記述する JSON ファイルです。
出力列の並び順は **出力テンプレート CSV の 1 行目** で決まり、変換定義では各列の値の作り方だけを指定します。

```json
{
  "name": "定義の名前（任意・画面表示用）",
  "input":   { "encoding": "auto", "delimiter": "," },
  "output":  { "encoding": "shift_jis", "newline": "crlf", "quote": "auto", "onUnmappable": "error" },
  "autoMapSameName": true,
  "exclude": [ ... ],
  "columns": { "出力列名": { ... } }
}
```

すべての項目は省略できます。変換定義を指定しない場合は、入力と出力で **同じ名前の列だけ** がそのまま対応付けられます。

## input

| キー | 値 | 既定 |
|---|---|---|
| `encoding` | `auto` / `utf-8` / `utf-8-bom` / `shift_jis` | `auto`（BOM と UTF-8 としての妥当性から判定） |
| `delimiter` | 区切り文字 | `,` |

## output

| キー | 値 | 既定 |
|---|---|---|
| `encoding` | `shift_jis`（Windows-31J） / `utf-8` / `utf-8-bom` | `shift_jis` |
| `newline` | `crlf` / `lf` | `crlf` |
| `quote` | `auto`（必要な値だけ `"` で囲む） / `all`（すべて囲む） | `auto` |
| `onUnmappable` | 出力文字コードで表現できない文字（例: 𠮷）があったとき。`error`: 変換を中止して箇所を表示 / `replace`: `?` に置き換えて警告 | `error` |

> 給与・人事データでは氏名の外字が化けると実害が大きいため、既定では置き換えずにエラーにします。

## autoMapSameName

`columns` に書かれていない出力列について、入力に同名の列があれば自動で対応付けます（既定 `true`）。
`false` にすると、`columns` に書かれていない列はすべて空欄になります。

## columns

キーが出力列名、値が列の作り方です。値の取り方は次の 4 種類から **1 つ** を指定します。

| 指定 | 意味 | 例 |
|---|---|---|
| `from` | 入力列の値 | `{ "from": "社員番号" }`（文字列だけ書いた `"社員番号"` も同じ意味） |
| `value` | 固定値 | `{ "value": "51" }` |
| `concat` | 複数の列・文字列を結合 | `{ "concat": ["姓", "名"], "separator": "　" }`<br>文字列を挟む場合: `["姓", { "value": "/" }, "名"]` |
| `sequence` | 連番 | `{ "sequence": { "groupBy": "社員番号", "start": 1 } }`<br>`groupBy` を指定すると、その列の値ごとに 1 から数え直す（扶養家族の通し番号など） |

取り出した値には、次の順で加工が適用されます。

1. `transform` … 値の変換（下表）。配列で複数指定すると順に適用
2. `map` … 値の置き換え表。`"*"` キーは「どれにも一致しなかった場合」
3. `default` … ここまでの結果が空文字なら入れる値

```json
"障害者区分": {
  "from": "障害者区分",
  "transform": ["trim"],
  "map": { "1": "1一般", "2": "2特別", "*": "0" }
}
```

### transform 一覧

| 指定 | 内容 | 例 |
|---|---|---|
| `"trim"` | 前後の空白を除去 | `" A "` → `"A"` |
| `"upper"` / `"lower"` | 英字の大文字化 / 小文字化 | |
| `"fullwidth"` | 半角英数記号・半角カナ・半角スペースを全角に（Excel の DBCS 関数相当） | `ﾔﾏﾀﾞ ﾀﾛｳ` → `ヤマダ　タロウ` |
| `"halfwidth"` | 全角英数記号・全角カナ・全角スペースを半角に（Excel の ASC 関数相当） | `ヤマダ　タロウ` → `ﾔﾏﾀﾞ ﾀﾛｳ` |
| `"katakana"` | ひらがなをカタカナに | `やまだ` → `ヤマダ` |
| `"digits"` | 数字以外を除去 | `000-0001` → `0000001` |
| `{ "zeroPad": 6 }` | 指定桁まで先頭を 0 で埋める（空欄は空欄のまま） | `101` → `000101` |
| `{ "date": "YYYYMMDD" }` | 日付の書式を揃える。入力は `2024/4/1`・`2024-04-01`・`20240401`・`2024年4月1日` に対応。出力書式は `YYYY` `MM` `DD` `M` `D` の組み合わせ。日付として解釈できない値はそのまま | `1985/4/1` → `19850401` |
| `{ "replace": { "pattern": "-", "with": "", "flags": "g" } }` | 正規表現で置換 | |

## exclude

条件に一致した入力行を出力から除外し、**除外リスト CSV**（行番号・除外理由・元の全列）に書き出します。
上から順に評価し、最初に一致したルールの `reason` が除外理由になります。

```json
"exclude": [
  { "column": "在籍区分", "op": "eq", "value": "退職", "reason": "退職者のため除外" },
  { "column": "税区分", "op": "notIn", "value": ["1"], "reason": "税区分が甲欄以外のため除外" },
  {
    "all": [
      { "column": "雇用形態", "op": "eq", "value": "パート" },
      { "column": "時給", "op": "empty" }
    ],
    "reason": "パートで時給が未設定"
  }
]
```

| op | 意味 |
|---|---|
| `eq` / `ne` | 一致する / しない |
| `in` / `notIn` | 配列のいずれかに一致する / しない |
| `empty` / `notEmpty` | 空である / 空でない |
| `regex` | 正規表現に一致する |

比較は前後の空白を除いた文字列同士で行います。`all`（すべて満たす）と `any`（いずれかを満たす）は入れ子にできます。

除外リストは元データの文字を落とさないよう、出力設定にかかわらず **BOM 付き UTF-8**（Excel でそのまま開ける形式）で出力します。

## 検証

変換の前に定義を検証し、次のような問題があれば変換を行わずにすべて列挙します。

- `from` / `concat` / `groupBy` / `exclude` で参照している列が入力 CSV に無い
- `columns` のキーが出力テンプレートに無い
- 値の取り方が 0 個または 2 個以上指定されている
- 未知の `transform` / `op`、引数の不足
